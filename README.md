# Koi

Koi is an AI-powered disruption recovery assistant built for the UCSC AI Hackathon 2026 — Cisco Cloud AI Track (Level 2).

When an unexpected change disrupts someone's plans, Koi identifies the cascading effects and coordinates specialized AI agents to negotiate a recovery plan.

## Features
- Disruption and impact detection
- Dynamic AI agent selection
- Multi-agent negotiation
- Budget and schedule validation
- Recovery plan recommendations

## Tech Stack
- React + Vite
- Tailwind CSS
- n8n
- Ollama API
- Python / FastAPI
